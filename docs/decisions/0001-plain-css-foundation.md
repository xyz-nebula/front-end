# ADR 0001: Plain CSS foundation

- Статус: принято
- Дата: 2026-09-27

## Контекст

Tailwind использовался только как источник preflight, а MUI и Emotion — только
для `ThemeProvider` и `CssBaseline`. Компоненты приложения уже оформлялись
обычным CSS с семантическими классами. Сохранение двух крупных зависимостей ради
baseline увеличивало размер dependency graph и оставляло несколько владельцев
глобального reset-поведения.

## Решение

Удалить Tailwind, `@tailwindcss/vite`, MUI и Emotion вместе с их providers.
Единственным foundation становится минимальный reset в
`src/styles/global.css`. Экранные и компонентные стили продолжают использовать
семантические scoped-классы; namespace `arena-*` и изоляция landing сохраняются.

## Последствия

- Reset, глобальные переменные и общие примитивы принадлежат `global.css`.
- Tailwind utilities, MUI-компоненты, `sx` и Emotion не используются.
- Новая styling-библиотека или возврат удалённых библиотек требуют отдельного
  решения, проверки размера bundle и визуальной проверки всех экранов.
- После изменений UI, CSS или reset обязателен `npm run visual:smoke` и ручной
  просмотр относящихся к задаче desktop/mobile PNG.
- Для механического разделения компонентов сохраняются before/after PNG и
  SHA-256 manifest вне репозитория; диагностические изображения не коммитятся.
