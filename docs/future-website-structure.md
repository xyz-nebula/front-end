# Структура страниц и окон сайта

## Пользовательская часть

### `/` — Лендинг

Главная презентационная страница продукта. Содержит описание «Арены переговоров», её возможностей, принципов работы и преимуществ.

### `/login` — Вход

Страница входа зарегистрированного пользователя в систему.

### `/register` — Регистрация

Страница создания нового аккаунта пользователя.

### `/home` — Главная

Основной экран пользователя. Содержит доступные кейсы для прохождения, прогресс пользователя, статистику и элементы геймификации.

### Просмотр кейса — модальное окно

Открывается при выборе кейса на главной странице. Позволяет ознакомиться с полной информацией о кейсе, его ситуацией и ролями, а также выбрать свою роль. Кнопка **«Начать подготовку»** переводит пользователя на страницу подготовки.

### `/cases/:id/preparation` — Подготовка

Экран подготовки к переговорам. Пользователь анализирует конфликт, формулирует цель и стратегию, определяет интересы, BATNA, границы торга, аргументы и сценарий действий. Для отдельных полей предусмотрена возможность проверки и получения обратной связи от AI.

### `/cases/:id/duel` — Переговоры

Экран проведения переговоров с AI-оппонентом. Отображает участников, таймер и транскрипцию диалога. Пользователь может использовать микрофон, завершить переговоры и просматривать свою подготовку во время поединка.

### `/cases/:id/result` — Результат переговоров

Экран итогового разбора переговоров. Показывает результат поединка, достижение целей, сильные стороны и ошибки пользователя, упущенные возможности, анализ отдельных реплик и рекомендации для дальнейшего развития.

### `/settings` — Настройки

Экран управления настройками пользователя и приложения.

# Административная часть

### `/admin` — Главная админки

Основной экран администратора со списком кейсов. Позволяет просматривать существующие кейсы, создавать новые, редактировать и удалять их.

### Создание кейса — модальное окно

Модальное окно для создания нового кейса. Содержит форму настройки кейса и необходимые параметры сценария. Кнопка **«Сохранить»** создаёт кейс.

### Редактирование кейса — модальное окно

То же модальное окно, что и при создании кейса, но с уже заполненными данными выбранного кейса. Позволяет изменить информацию и настройки кейса. Доступны кнопки **«Сохранить»** и **«Удалить»**.
