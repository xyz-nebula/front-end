# Архивные референсы landing

PNG в этой папке — архивные дизайн-референсы лендинга «Арены переговоров».
Их нужно сохранять как историю визуального направления. Они не являются
обязательными visual-regression baselines: актуальный интерфейс и его поведение
проверяются сценариями в `tests/visual/`.

В отличие от этих референсов, `artifacts/visual-smoke/` содержит временные
диагностические скриншоты Playwright. Runner очищает эту папку перед прогоном;
`artifacts/`, test results и сборки не добавляются в Git. Для механического
CSS-рефакторинга можно сохранить отдельный before/after baseline вне репозитория,
не заменяя им PNG в `examples/`.
